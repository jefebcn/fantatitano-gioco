## Ritratti delle carte con Gemini
1. Gemini (account di Alex o quelli autorizzati, chat nuova ogni 3 fogli): un foglio quadrato 2x2 con quattro
   calciatori a mezzo busto, sfondo #00FF00 (magenta #FF00FF se la maglia è verde), maglia da calcio vera coi colori
   della squadra, pose diverse, «volti inventati, nessuno somigliante a persone famose».
2. Il pulsante «Scarica» di Gemini a volte non consegna il file a Chrome: si prende l'immagine originale (=s0) che la
   pagina scarica e la si salva con un link `download` dalla pagina stessa, col nome `foglio-<n>.jpg`.
3. `python3 scripts/ritratti_gemini.py foglio-<n>.jpg g id1,id2,id3,id4` → `public/img/ritratti-carte/`.
4. Foglio di controllo numerato per Alex; i volti scartati si rifanno **cambiando la descrizione del viso** (forma,
   naso, capelli, barba, età): con la stessa descrizione Gemini rifà quasi la stessa faccia.
5. Se si aggiungono o si tolgono volti: `node scripts/volti.mjs` riscrive `src/dati/volti.json` dalla cartella;
   `npm run prova` si ferma se a un volto manca il file da 512 o da 256, o se c'è un file che l'elenco non conosce.
